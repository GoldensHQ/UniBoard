# UniBoard — умный буфер обмена для Windows

UniBoard — настраиваемый менеджер буфера обмена, который живёт в трее и помогает
вставлять скопированное быстрее: пока вы печатаете, он показывает подсказку,
а `Ctrl+Space` вставляет её за вас.

## Возможности

- **Умные подсказки при печати.** Скопировали ссылку → начали печатать её начало
  (`htt…`) → всплыла подсказка → `Ctrl+Space` — и ссылка вставлена целиком.
- **История буфера** (`Ctrl+Alt+V`): окно с поиском, предпросмотром,
  закреплением (`Ctrl+P`), удалением (`Delete`) и вставкой (`Enter`).
- **Сниппеты**: короткий триггер разворачивается в длинный текст
  (например `;прив` → «Привет! Как дела?»). Редактор — в настройках.
- **Умное распознавание типов**: ссылки, e-mail, HEX-цвета, JSON, изображения,
  скопированные файлы — у каждого свой значок и приоритет в подсказках.
- **Вставка последнего элемента** (`Ctrl+Alt+X`) без открытия окна.
- **Настройки**: горячие клавиши, способы вставки, исключения для приложений,
  автозапуск с Windows, лимиты истории — всё в трее → Настройки.

## Установка и запуск

Нужен Python 3.10+ (в системе уже установлен, `py -3`).

```bat
cd UniBoard
run_uniboard.bat
```

Скрипт сам установит зависимости (`pillow`, `pystray`, `pywin32`) и запустит
приложение без консоли. После запуска появится значок «U» в трее.

Для отладки запускайте с консолью: `py -3 uniboard.py` (лог продублируется на экран,
полный лог всегда в `%APPDATA%\UniBoard\uniboard.log`).

## Как пользоваться

| Действие | Как |
|---|---|
| Вставить подсказку | печатаете начало скопированного → `Ctrl+Space` |
| Выбрать другой вариант | клик мышью по строке |
| Скрыть подсказку | пробел, клик в другое окно, авто-таймаут |
| Открыть историю | `Ctrl+Alt+V` (или двойной клик по значку) |
| Вставить последний элемент | `Ctrl+Alt+X` |
| Закрепить в истории | `Ctrl+P` |
| Пауза подсказок / записи | меню значка в трее |

Подсказки срабатывают на **начало** скопированного текста (без учёта регистра).
Пробел сбрасывает буфер набора — так подсказка не мешает обычному набору текста.
По умолчанию обычные длинные тексты предлагаются только если они закреплены;
ссылки, e-mail, цвета, JSON и сниппеты — всегда (это можно изменить в настройках).

## Настройки (что можно менять)

- Минимум символов до появления подсказки и число вариантов.
- Горячая клавиша вставки подсказки (по умолчанию `Ctrl+Space`).
- Способ вставки: печать посимвольно (надёжно для текста) или через буфер обмена
  (быстро для больших объёмов; предыдущее содержимое буфера возвращается обратно).
- Авто-разворачивание сниппетов при точном вводе триггера (режим espanso/AHK).
- Исключённые приложения — по имени процесса (менеджеры паролей добавлены по умолчанию).
- Автозапуск с Windows, размер истории, интервал опроса буфера.

## Как это работает (внутри)

- **Низкоуровневых хуков нет вообще.** Ранние версии использовали
  `WH_KEYBOARD_LL` и вызывали системные зависания ввода на некоторых системах
  (система синхронно ждёт колбэк хука на каждом нажатии). Теперь:
  - **Raw Input** (`WM_INPUT`, `RIDEV_INPUTSINK`): система *доставляет* события
    клавиатуры в наше скрытое окно асинхронно и ничего не ждёт от нас — фриз
    ввода по построению невозможен; замедлится наш поток — пострадает только он.
  - **RegisterHotKey** — официальный API для горячих клавиш
    (`Ctrl+Space`, `Ctrl+Alt+V`, `Ctrl+Alt+X`).
- Поскольку «поглотить» клавишу без хука нельзя, Tab/↑/↓/Esc проходят в
  приложения как обычно; вставка подсказки — горячей клавишей `Ctrl+Space`.
- Расшифровку символа по раскладке (вкл. кириллицу) делает отдельный поток
  с таймаутом (`ToUnicodeEx` не в главном потоке).
- Собственные инъекции клавиш (Backspace/текст/Ctrl+V) Raw Input тоже видит —
  они отфильтровываются временным окном после вставки, чтобы не зациклиться.
- Набранный буфер (последние символы без пробелов) сверяется с историей и
  сниппетами; окно подсказки рисуется рядом с кареткой (`GetGUIThreadInfo`)
  и **не забирает фокус** у целевого приложения.
- Вставка подсказки: нужное число `Backspace` и текст событиями
  `KEYEVENTF_UNICODE` — работает с любой раскладкой.
- Наблюдатель буфера следит за `GetClipboardSequenceNumber` и пишет текст,
  файлы (CF_HDROP) и картинки (CF_DIB → PNG) в `%APPDATA%\UniBoard`.

## Если что-то зависло

Завершите процесс через Диспетчер задач: `pythonw.exe` из папки UniBoard либо
задачу `pyw.exe`. Лог: `%APPDATA%\UniBoard\uniboard.log`. Ввод системы при этом
останется работать: перехватчиков, которые могут его заморозить, больше нет.

## Ограничения

- Окна, запущенные **от администратора**, не видят подсказки (UIPI) — при
  необходимости запускайте и UniBoard от администратора.
- В полях паролей подсказки не отключить программно: держите менеджеры паролей
  в списке исключений и выключайте подсказки из трея, когда это критично.
- Приложения, редактирующие текст на лету (автозамена Word), могут немного
  сбивать подсчёт Backspace.
- Вставка изображений/файлов идёт через буфер обмена (Ctrl+V).

## Структура проекта

```
UniBoard/
├── uniboard.py / uniboard.pyw   — точки входа (с консолью / без)
├── run_uniboard.bat             — установка зависимостей + запуск
├── requirements.txt
├── selftest.py                  — быстрая проверка логики
└── core/
    ├── app.py          — оркестратор: потоки, логика подсказок, трей
    ├── config.py       — настройки, горячие клавиши, автозапуск
    ├── history.py      — история, сниппеты, классификация, подбор кандидатов
    ├── rawinput.py     — слушатель клавиатуры через Raw Input (без хуков)
    ├── registrar.py    — горячие клавиши через RegisterHotKey
    ├── kbd.py          — эмуляция ввода (SendInput)
    ├── decoder.py      — расшифровка раскладки в отдельном потоке (безопасно)
    ├── winapi.py       — каретка, окна, мониторы, процессы
    ├── clipboard.py    — чтение/запись буфера (текст, файлы, картинки)
    ├── watcher.py      — наблюдатель буфера обмена
    ├── popup.py        — окно подсказок
    ├── history_ui.py   — окно истории с поиском
    ├── settings_ui.py  — окно настроек и редактор сниппетов
    └── theme.py        — тёмная тема
```
